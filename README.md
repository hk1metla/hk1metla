## Featured project

### [Skillens: Educational Content Recommendation](https://github.com/hk1metla/CM3070-Skillens)

My bachelor's final project explores educational recommendation using TF-IDF, ItemKNN collaborative filtering and weighted hybrid fusion. The repository includes an offline evaluation pipeline using OULAD and a Streamlit demonstration interface.

The project connects data preparation, recommendation models, ranking evaluation and learner-facing explanations.
